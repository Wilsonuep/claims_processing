# Claims Processing — AM/UAM Evaluation Results

A courtesy release of the **evaluation results** produced for a master's thesis
on Polish-language claim verification / fact-checking. Shared in the interest of
**research transparency and reproducibility**.

- **Source code & full evaluation pipeline:** <https://github.com/Wilsonuep/claims_processing>
- **License: MIT** (see [License](#license) below)
- **Language:** Polish (`pl`)

All artifacts here were generated by running the agents defined in the repository
above against the **AM / UAM (AMU-CAI)** Polish multiple-choice benchmark
(labels `0–3`, i.e. answer choices **A–D**).

> **No question text is redistributed here.** Both files contain **only
> evaluation results** — predictions, gold labels, token/time metrics. Each row
> carries a `claim_id` that **matches the row id in the original AM benchmark**
> (`data/benchmarks/am_benchmark.db` in the source repo); join on `claim_id`
> there to recover the questions. The discontinued experimental agents
> `uam_ga_web_tool_arch` (misconfigured web-ReAct agent) and
> `uam_ga_rag_decomp_arch` (redundant duplicate of the decomposition + BM25
> pipeline) have been **removed** from both files.

## Files

Two **Parquet** files, one row per `(agent, model, claim)` evaluation. Active
agents only: `uam_ga1`–`uam_ga5` (single → debate). All retrieval agents
(`uam_ga2`–`uam_ga5`) use **BM25** retrieval; `RAG_MODE` was never set to
`vector`/`hybrid`, so no result used vector/embedding retrieval.

| File | Origin (in repo) | Contents |
|---|---|---|
| `full_benchmark.parquet` | `results/results_am_benchmark.db` | Full-benchmark run (up to 18,820 questions) — per-claim predictions, all evaluated models. 228,211 rows. |
| `subsample_analyzed.parquet` | `results/results_am_subsample.db` | The 4,000-question common subsample analysed across four models (no question text). 80,000 rows. |

```python
from datasets import load_dataset
full = load_dataset("Wilsonuep/claims_processing_results", "full_benchmark", split="train")
sub  = load_dataset("Wilsonuep/claims_processing_results", "subsample_analyzed", split="train")
```

### `full_benchmark.parquet`
- **No question text.**
- **Full** 18,820-question coverage for **Bielik-11B** and **llama3.1:8b**.
- Partial (4k-subset) coverage also present for **qwen2.5:7b** and **Llama-PLLuM-8B**.

### `subsample_analyzed.parquet`
- The 4,000-claim common subsample × four models × agents `uam_ga1`–`uam_ga5`.
  No question text; `claim_id` still references the original AM benchmark.
- This is the result set behind the cross-model analysis notebooks in the source repo.

### Schema (both files)
`agent_name`, `claim_id`, `benchmark_name`, `original_label` (gold, 0–3),
`model_label` (prediction), `is_correct`, `total_tokens`, `prompt_tokens`,
`completion_tokens`, `time_thought` (seconds), `raw_output`, `model_name`,
`created_at`.

- Agent naming follows `uam_ga<N>__<model-suffix>`.
- Labels `0 / 1 / 2 / 3` map to answer choices `A / B / C / D`.

## Loading

Besides `load_dataset(...)` above, the Parquet files load directly with pandas,
polars, or DuckDB (SQL over Parquet):

```python
import pandas as pd
df = pd.read_parquet("full_benchmark.parquet")

# or SQL without a database:
import duckdb
duckdb.sql("SELECT model_name, AVG(is_correct) FROM 'full_benchmark.parquet' GROUP BY 1")
```
